# Auto-repair-system

An LLM-assisted auto-repair system manager in Python (repository description: "System manager with LLM"). It is organised in layers: error detection, an AI diagnosis layer, automatic repair execution, verification, and audit logging, with Google Drive integration. A guide (AUTO_REPAIR_GUIDE.md) is included.
